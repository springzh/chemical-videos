# brief — mPEG-NHS 5000（横屏 16:9，≈96 s，100 bpm，深海蓝；a 橙 = 甲氧基，accent 青 = PEG，b 紫 = NHS 酯）
产品族：线性 PEG 试剂（camera-and-scenes.md「Linear PEG reagents」表）。用户重点：偶联、水解竞争、干燥低温储存。

| 场景 | 3D 动作 | 特写 / 镜头 | 读数（公式） |
|---|---|---|---|
| intro (full) | 粉色蛋白 + 6 个赖氨酸；mPEG 链从左侧漂近；“蛋白质”处“?”+冲击波；“今天”标题 mPEG-NHS 砸入 | 开场环绕拉远，再升机位给标题让位 | — |
| 01 一头惰性·一头活性 | Mol(ome)：链按“线性”生长，甲氧基在“甲氧基”弹出发光，NHS 环在“活性酯”弹出；“氨基”时一个游离胺靠近；“柔顺”链摆幅加大 | 先推向甲氧基端，再推向 NHS 端，最后拉回全链 | n = 5000/44 = 114 EO；R_F = 0.35·114^0.6 = 6.0 nm |
| 02 偶联·酰胺键 | NHS 环对准赖氨酸胺基靠近，pH 滑块 7→8.5 时胺基变亮；“酰胺键”成键发光、酰胺端帽出现；“释放”NHS 环飞离 | 成键时推近反应点，“接上”拉回 | f = 1/(1+10^(pKa−pH))，pKa 10.5 → pH 8.5 时 0.99 % |
| 03 水解竞争 | 6 条链冲向蛋白；水分子扎进其中 3 个酯 → 变灰、NHS 掉、灰色 COOH 帽；pH 升高水分子运动加快；“谁先到”另 3 条成键 | 推近第一个被水解的头，拉回全景 | t½ ≈ 4 h·10^(7−pH)：pH 7.5 → 1.3 h，pH 9 → 2.4 min（变红） |
| 04 PEG 化的收获 | 12 条链（蘑菇态线团）挂在蛋白上，水合壳 + 水分子；异种蛋白靠近被弹开；“循环”整体漂移 + 弧形箭头 | 缓慢拉远 | R_F = 6.0 nm |
| 05 储存·干燥低温 | 试剂瓶：−20 °C 结霜，水滴被弹开（干燥），瓶盖旋紧（密封），氩气充满顶空；“室温”霜化、开盖；“吸潮”水滴冲向冷瓶口（警示） | 慢环绕 | 溶液 −20 vs 25 °C 速率比 exp(Ea/R·Δ(1/T)) = 151 倍（Ea 70 kJ/mol）；受潮 pH 8 放置 1 h 剩余 0.5^(60/24) = 17.7 %（变红） |
| outro (full) | 主分子在标题上方，四角 PEG 化蛋白 | 缓慢后拉 | — |
