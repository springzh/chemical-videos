# 重结晶：为什么热溶解、冷析出就能提纯？（精读）

受众：高中化学竞赛学生。术语用到「溶解度、饱和、析出、晶格、母液」，不讲固溶体和相图。
材料：用户未提供，按教材常识写（出处注「教材常识，待核对」）。例子用苯甲酸从水中重结晶（经典教学实验，溶剂是水，没有易燃试剂）。

一句话核心：目标物在热溶剂里溶得多、冷溶剂里溶得少，冷却时多出来的部分析出；杂质量少，冷下来也还没到它自己的溶解上限，留在母液里；晶格只接纳形状对得上的同种分子，慢慢长时杂质插不进去。

## 实验与目的

粗苯甲酸（带少量有色杂质）→ 加最少量沸水溶解 →（有不溶杂质时趁热过滤）→ 自然冷却析晶，再冰浴 → 抽滤，用少量冷水洗涤 → 得到较纯的白色晶体，杂质留在母液。

## 机理骨架

现象（发黄的粗品 → 雪白晶体，杂质去哪了？）→ 宏观：热溶、冷析 → 溶解度曲线：热时上限高、冷时上限低，差值析出 → 微观计数：20 个小苯 + 3 个小杂，冷后溶液只容得下 4 个小苯，析出 16 个；小杂 3 个没到它的上限，全留在溶液 → 晶格：只有形状对得上的才能嵌进去 → 回到宏观：过滤，晶体留在滤纸，杂质随母液走 → 变量：冷却速度（慢：大而纯；急冷：小而碎，包进杂质）→ 规则：最少量热溶剂、先自然冷却再冰浴、少量冷溶剂洗涤 → 测验：溶剂加多了 → 析出少、损失多。

## 常见误解（做 twist / 测验）

- 「冷得越快越好，直接冰浴」→ 急冷晶体小、包进杂质（#6）。→ 变量场景的 twist。
- 「溶剂多一点更保险」→ 析出少、损失大（#7）。→ 测验。
- 「杂质是被『冻』在溶液里的」→ 杂质留在溶液是因为量少、没饱和（#3）。

## 安全

热溶液、沸水防烫，用隔热手套或坩埚钳；加热时防暴沸。片中在操作场景显示安全角标。
