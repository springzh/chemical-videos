# 科学准确性与安全

化学实验视频最容易出的问题不是画面难看，而是讲错：颜色不对、数字是编的、把简化当成事实、漏了安全。这一页规定 `reading.md` 怎么写，以及哪些东西必须在画面上标出来。

## `reading.md`

```
# <实验名>：精读
受众：高中 / 本科有机实验 / 研究生……（决定术语深度）
一句话核心：<原理一句话，例如「硅胶表面的 Si–OH 会和极性基团形成氢键，极性越大停留越久」>

## 实验与目的
## 物质表（每种物质：中文名、英文名、结构要点、极性 / 酸碱性、真实颜色、角色昵称、画面颜色）
## 机理骨架（现象 → 微观原因 → 变量 → 规则）
## 事实表（片子里的每个数字、规则、结论，各有出处）
| # | 片中说法 | 数值 / 规则 | 出处 | 是否示意 |
## 常见误解（做 twist 和测验选项）
## 安全（试剂危害、操作要点）
## 简化与示意（片子里简化了什么、为什么可以这样简化）
## 不能写进片子的（说不清、有争议、出处不足的）
```

## 事实表的规矩

- **出处**写得具体：教材（《有机化学实验》第 x 版，第 n 章）、常用手册、综述，或「本片模拟，示意」。用户给了材料就以用户材料为准。
- 片子里**每一个数字**都要在事实表里：Rf 范围、比例、温度、pH、产率、分配系数。拿不准的数字不要写，改成定性说法（「大约四分之一」→「不到一半」）。
- 经验规则要写清楚**适用范围**：「Rf 0.2–0.35 适合快速柱层析」是硅胶正相、常规上样量下的经验值，不是定律。
- 计算出来的数（萃取几次后剩多少）写出算式，用第二种方法核对（直接代公式 + 逐次计算）。

## 必须标「示意」的情况

| 情况 | 例子 | 做法 |
|---|---|---|
| 物质本来无色，片中上了色 | 甲苯、苯甲醇的色带 | 色带旁 `schematicNote('颜色为示意')`，至少出现一次 |
| 数字是模拟出来的 | 「计时 4.1 秒对 9.1 秒」 | 计时胶囊旁边标「示意」；配音不要说成测量值 |
| 尺度被夸张了 | 分子画得和 OH 一样大 | `endnote` 统一说明 |
| 动态平衡被画成一次性事件 | 「EA 抢走了 OH」 | 配音或字幕里至少一次说「来回」「不停地」，或在 `reading.md`「简化」里写明 |

`script.json` 的 `endnote` 要写「颜色与数字为示意」或类似的话，有示意场景的在场景上标 `"schematic": true`，`lint.py` 会核对两者。

## 安全

- 稿子里出现易燃、有毒、腐蚀、强氧化的试剂时（`lint.py` 内置了一张常用试剂表），`script.json` 写 `"safety": ["石油醚、乙酸乙酯易燃，远离明火，在通风橱中操作"]`，并在第一次出现这些试剂的场景或 `practice` 场景里显示 `safetyBadge`，至少停留 3 秒。
- 讲操作时不演示危险的错误做法（例如给加热的密闭体系加压）。要讲反例，就用打叉的示意加文字说明。
- 不给出具体的危险品制备步骤。本技能做的是教学实验讲解，不是操作手册。

## 化学写法

- 下标、上标用 Unicode（SiO₂、CH₃、δ⁺ / δ−、R_f 写成 Rf），不要用 HTML 标签。
- 化学式里的短横用 en dash（Si–OH），字幕也一样。
- 比例写「石油醚∶乙酸乙酯 = 5∶1」时，字幕里用全角比号或冒号，配音写「五比一」。
- 物质第一次出现时，中文名 + 英文名都要上屏（名牌或骨架式旁边）。
