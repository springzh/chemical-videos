# 验收

## 逐场景自检（每写完一个场景）

`render.py --scene <id>` 出三张静帧，看拼图 `build/stills/sheet_9x16_<id>.jpg`（格子约等于手机大小）：

- 下拍后一拍那张：舞台上已经有东西，不只有标题。
- 文字没有溢出、没有互相压住；舞台元素没有进入字幕区（竖屏舞台 y > 900 的部分要留意）。
- 屏幕下方 25%（y > 1440）没有重要内容。
- 同一种物质在各个场景里是同一种颜色、同一个长相。
- 示意色、示意数字旁边有「示意」。
- 场景里有东西一直在动（粒子、浮动、计时、虚线）。

## 整片验收

`check.py`（本技能的包装版）之后，看完全部 `build/check_9x16_*.jpg`，按下表打分（1–10），记进 `qa/review_log.md`：

| 项 | 8 分的样子 |
|---|---|
| 讲得清楚 | 只看画面加字幕，能说出「为什么能分开」和那条实操规则 |
| 尺度 | 进出分子世界时观众知道换了尺度（推拉转场、聚焦、比例尺任选），没有突然换场景；不进微观的片子这项看宏观画面的比例是否可信 |
| 角色与动作 | 机理是演出来的（握手、停住、冲下去），不是贴字说明 |
| 科学准确 | 事实表里都有；示意都标了；没有把简化说成事实 |
| 节奏 | 没有超过 1 秒的空白下拍；结论条和小结有足够的阅读时间；测验倒计时 ≥ 5 秒 |
| 版式与安全区 | 竖屏下方 25% 是空的；字号在手机上看得清 |
| 完成度 | 没有草稿布局、占位文字、默认样式；转场有理由 |
| 安全 | 涉及危险试剂时有安全角标，停留 ≥ 3 秒 |

每项 8 分以上、`check.py` 没有 PROBLEM 才交付。

## 独立审查

派一个**没参与制作**的子代理（模型和制作者不同，例如 sonnet），给它下面这些，不要告诉它你觉得哪里好：

```
你是化学教学视频的审片人。请看这些文件：
- 抽帧拼图：<项目>/build/check_9x16_*.jpg（每行一个场景的三个时刻）
- 封面：<项目>/<output>_9x16.cover.png
- 配音稿：<项目>/script.md；事实表：<项目>/reading.md
按 <技能目录>/references/review.md 的评分表逐项打 1–10 分，每项给出依据（哪个场景、第几秒）。
另外单列：科学错误或容易误导的地方；文字溢出、重叠、看不清的地方；落在屏幕下方 25% 的重要内容。
只报告，不修改文件。
```

把结论记成「独立审查第 n 轮」。改完后再审一次，最多两轮。两轮后仍低于 8 分的项写进汇报的「已知不足」。
