# 视觉风格

浅色、扁平、矢量，像一本干净的实验讲义。风格参照一条有机化学实验系列短片，但不照搬：品牌名、角色名、原句和它的标志性道具（「一尺镜」）都不带进片子。

## 版式

竖屏 9:16 为主（1080×1920），横屏 16:9 可选。舞台是 1000×1000 的场景坐标，`index.html` 的 `LAY` 决定它放在哪里，`scripts/check.py` 的 `STAGE` 要和它一致。

| 区域 | 竖屏（px） | 横屏（px） | 放什么 |
|---|---|---|---|
| 角标 `brand` | y 70 | y 72 | 系列名 · 集数（「有机化学实验 · EP01」） |
| 标题区 | y 140–300 | 左栏 x 80–550 | 中文标题（`script.json` 的 `title`）+ 英文副标题（scene def 的 `en`） |
| 舞台 | y 330–1330 | x 600–1500 | 画面主体 |
| 比例尺（可选） | 右下角 (830, 1262) | (1300, 905) | 当前尺度：1 cm / 1 mm / 1 μm / 1 nm；场景不设 `scale` 就不显示 |
| 字幕 | 底边约在 y 1352 | y 972 | 白色圆角底的深色字，一次一条 |
| 平台界面区 | y > 1440、右侧 x > 960 | — | **不放重要内容**：抖音和视频号会在这里叠加简介、头像和按钮 |

舞台里的坐标：竖屏下舞台底部（y 900–1000）离字幕很近，主要的画面放在 y 40–880。场景设了 `scale` 时，舞台右下角（x > 760、y > 880）是比例尺的位置，不要放东西。竖屏的画面会在 y 1352 以下留出约 30% 的空白，这是给平台界面留的，不要为了「填满」把内容往下放。

## 配色（语义色，全片锁定）

| 键 | 色值 | 含义 |
|---|---|---|
| `bg` | `#EEF3F1` | 薄荷灰底，带极淡的点阵 |
| `bg2` | `#FFFFFF` | 卡片、TLC 板、字幕底 |
| `paper` | `#1F2A30` | 文字、仪器轮廓、Si 原子 |
| `dim` | `#7A8A86` | 英文副标题、说明文字 |
| `a` | `#2D4FD6` | 第一种物质 / 非极性 / 先出峰的那个 |
| `b` | `#1E8C6E` | 第二种物质 / 极性 / 被吸附的那个 |
| `accent` | `#F2A93B` | 起作用的基团：–OH、Si–OH、氢键、Rf 目标区间 |
| `good` / `bad` | `#2E9E6A` / `#E5484D` | 「刚好」/「太慢」「挤在一起」等评价标签 |
| `solvent` / `sand` / `silica` / `glass` | 浅蓝 / 沙黄 / 近白 / 灰绿 | 仪器材质 |
| `c3` / `c4` | 紫 / 橙红 | 第三、第四种物质（需要时） |

规则：同一种物质全片一种颜色；`accent` 只给「起作用的那个基团或那段区间」；物质的真实颜色和示意色冲突时，在画面上标「颜色为示意」（`schematicNote`）。

## 字体与字号

- 只用 Noto Sans SC（`fonts/NotoSansSC.ttf`，`new_project.sh` 从本机缓存链接）。标题 900，正文 700–800，英文 400。
- 舞台里最小字号 27（`MIN_FONT`）。英文注释（`small()`）可以用 22–26，因为它只是补充说明。
- 标题区的中文最多约 14 字（竖屏），超出会自动缩小字号。

## 角色与仪器

- 角色（`mol`）：纯色圆球 + 高光 + 两只白眼睛 + 可选的橙色基团小手。半径 40–80。待机时有轻微的上下浮动和眨眼（`poseMol` 自动加）。
- 溶剂分子：小灰点（不参与作用的，如石油醚）；能参与作用的溶剂画成带缩写的深色小球（`mol({ label: 'EA', r: 22 })`）。
- 仪器：粗轮廓线（5 px）、浅色填充、没有透视。色谱柱、TLC 板、分液漏斗、烧杯、圆底烧瓶、试管都在 `chem.js` 里。
- 骨架式：`skeletal()`，苯环加取代基，作用基团用 accent 色。

## 标志性的动作（照这几种来演）

| 动作 | 用来讲什么 | 组件 |
|---|---|---|
| **推进**：先锁定一个位置（聚焦圈套住色带、界面或一颗晶体），画面分级放大，下一个场景用 `enter: 'zoomIn'` 从中心放大、带模糊进入；需要时比例尺跟着变 | 从宏观进入分子尺度（只在机理在分子层面时用） | `setColumn({ lens })`、场景内自己做缩放 + scene `enter`（`scale` 可选） |
| **拉远**：`enter: 'zoomOut'`，标尺回到 1 cm | 回到宏观 | 同上 |
| **长出来的手**：Si 原子上一个个长出 OH | 表面上有活性位点 | `setSurface({ oh })` |
| **握手**：角色的手和墙上的 OH 之间拉一条流动的虚线，角色停住、被轻轻拽回 | 氢键、吸附 | `hbond` + `setBond` |
| **赛跑计时**：顶部两个计时胶囊，被拉住的那个读数涨得更快，先到终点的停表 | 保留时间、洗脱顺序 | `timerPill` / `setTimer` |
| **抢位置**：溶剂小球一个个占住 OH，被拉住的角色被挤开、冲下去 | 竞争吸附、溶剂强度 | `track` 的 sites + `mol({ label })` |
| **出峰**：色带流出柱底的同一刻，检测器曲线画出峰 | 宏观结果 | `setColumn` + `setChart` |
| **并排对比**：三块 TLC 板，三种比例，配评价标签 | 选条件 | `tlc` / `setTLC` + `tagPill` |
| **量出来**：板上画出 a、b 两个箭头，公式卡落下 | 定量规则 | `setTLC({ arrows })` + `termCard` |

## 运动

沿用 article-video 的 `references/motion.md`（弹簧、错峰、三层运动、第一拍要有东西落下）。浅色扁平风格另外注意：
- 不用颗粒、暗角、发光；阴影只用 `chemShadow`（卡片和板）。
- 「环境运动」来自溶剂粒子流动、角色浮动和眨眼、计时器走秒、虚线流动。`check.py` 统计 1 秒以上的静止画面，超过 5% 就不合格。
- 转场：默认 `fade`（上浮淡入）；进入分子世界用 `zoomIn`，回到宏观用 `zoomOut`；接着上一个场景的同一个画面继续演（同一条赛道、同一张题卡）用 `none`，硬切，画面不跳。不用 iris / slash，它们和讲义风格不搭。
